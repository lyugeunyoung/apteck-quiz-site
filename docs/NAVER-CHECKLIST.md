# 네이버 노출 체크리스트

`github.io` 서브패스로 운영하기로 한 결정([`docs/DECISIONS.md`](DECISIONS.md) #1) 때문에, 네이버
쪽 노출은 구글보다 더 사람이 직접 챙겨야 하는 부분이 많습니다. 아래는 그 실무를 매일/매주/최초 1회로
나눈 체크리스트입니다. IndexNow는 네이버에 통하지 않으므로([`docs/DECISIONS.md`](DECISIONS.md) #7)
이 체크리스트가 네이버 쪽의 사실상 유일한 "빠른 수집 요청" 수단입니다.

## 최초 1회 (아직 안 했다면 최우선)

- [ ] [네이버 서치어드바이저](https://searchadvisor.naver.com)에 사이트 등록 + HTML 태그 소유확인
      (`admin.html` → "4. 사이트 전역 설정"에서 코드 입력 → 저장하면 전체 페이지에 즉시 반영)
- [ ] 서치어드바이저에서 `sitemap.xml`과 `feed.xml` 둘 다 제출
- [ ] `robots.txt`에 `User-agent: Yeti` 블록이 있는지 확인(네이버 크롤러 전용 규칙 — 이미 반영됨)

## 매일 (1~2분)

- [ ] 오늘 새로 갱신한 앱 페이지 URL 1~3개를 서치어드바이저 "요청 > 수집 요청"에 직접 제출
      (전체 URL을 매일 넣을 필요는 없음 — 그날 실제로 바뀐 것 위주로 충분)
- [ ] `feed.xml`이 오늘 갱신 항목을 포함하는지 브라우저로 한 번 열어 확인
      (`https://사용자명.github.io/저장소명/feed.xml`)

## 매주 (2~3분)

- [ ] 서치어드바이저 "요청 현황"에서 최근 제출한 URL들의 수집 상태(수집됨/실패)를 확인
- [ ] 서치어드바이저 "웹 마스터 도구 > 사이트 최적화" 리포트에 새로 뜬 경고가 있는지 확인
- [ ] 네이버 검색창에 대표 앱 2~3개 이름 + "정답"으로 직접 검색해 실제 노출 순위 변화를 체감 확인
      (예: "토스 행운퀴즈 정답", "카카오뱅크 AI 이모지 퀴즈 정답 오늘")

## 참고 — 이 사이트가 이미 자동으로 해주는 것

| 항목 | 자동 처리 위치 |
|---|---|
| `sitemap.xml`/`feed.xml`을 항상 최신 데이터로 재생성 | `scripts/build.js` (수동 저장·자동 동기화 양쪽에서 매번 실행) |
| `lastmod`을 실제 콘텐츠 변경일로 기록 | `templates.renderSitemap` |
| 네이버 소유확인 메타 태그 삽입 | `templates.headBlock` — `site.naverSiteVerification` 값이 있을 때만 |
| `robots.txt`의 `Yeti` 허용 규칙 | 저장소 루트 `robots.txt` |

사람이 직접 해야만 하는 것은 위 체크리스트의 "수집 요청" 제출뿐입니다 — 네이버는 IndexNow를 지원하지
않아 이 부분만큼은 자동화할 방법이 없습니다.
