1. GitHub 저장소 연결

이 페이지는 아래 정보로 GitHub Contents API에 직접 접속해 data/quizzes.json과 페이지 HTML을 커밋합니다. 토큰은 어디로도 전송되지 않고 이 브라우저에만(선택 시) 저장됩니다. Settings → Developer settings → Fine-grained tokens에서 해당 저장소의 Contents: Read and write 권한만 부여한 토큰을 만들어 사용하세요.

2. 구글 시트 연동

문제·정답·해설을 구글 시트에 정리해두면 두 가지 방식으로 쓸 수 있습니다. ① 자동 동기화 — 아래 "자동 동기화 켜기"를 한 번 눌러두면, 이후로는 시트에 값만 입력해도 약 20분마다 GitHub Actions가 자동으로 읽어와 사이트에 반영합니다(관리자 페이지를 열 필요 없음). ② 수동 불러오기 — "시트 불러오기"를 누르면 지금 이 화면에서 바로 미리 채워볼 수 있습니다.

시트 첫 줄은 헤더로 date, app_id, question, choice1, choice2, choice3, choice4, answer, explanation, image_url 열을 사용하세요 (순서는 상관없고, choice·image_url은 비워도 됩니다). app_id는 아래 앱 목록에서 각 앱을 선택했을 때 URL이나 페이지 소스에서 확인할 수 있는 영문 ID와 정확히 같아야 합니다. 카카오뱅크 AI 이모지 퀴즈처럼 회차가 있는 앱은 round_time 열에 08:00/12:00/20:00 중 해당 회차를 추가로 적어주세요 — 자동 동기화만 회차별 데이터를 지원합니다(수동 불러오기는 회차 없는 일반 앱만 지원).

시트를 만든 뒤 파일 → 공유 → 공유에서 "링크가 있는 모든 사용자 – 뷰어"로 설정하고, 아래 CSV 주소 형식을 사용하세요:
https://docs.google.com/spreadsheets/d/시트ID/export?format=csv&gid=시트탭ID

3. 퀴즈 앱 목록

수정할 앱을 탭하면 아래 입력 폼에 불러옵니다. 🟢 점은 오늘 이미 갱신된 앱입니다.

4. 오늘의 퀴즈 입력

저장하면 data/quizzes.json, 해당 앱의 상세 페이지, 홈 화면(index.html)이 한 번에 갱신되어 커밋됩니다.

항상 저장하는 날 기준 당일 날짜로 자동 등록됩니다 (직접 바꿀 수 없음).

드라이브 파일을 "링크가 있는 모든 사용자 – 뷰어"로 공유한 뒤 그 링크를 붙여넣고 [변환]을 누르면 바로 표시 가능한 이미지 주소로 자동 변환됩니다. 구글 드라이브는 트래픽이 몰리면 이미지가 일시적으로 안 뜰 수 있어, 중요한 이미지는 저장소의 assets/img/ 폴더에 직접 올려 ../assets/img/파일명.jpg 형태로 넣는 것이 더 안정적입니다.
